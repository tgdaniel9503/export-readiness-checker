# 수출 준비도 점검 어시스턴트 (MVP)

중소기업 상담 시 기업정보와 54개 자가진단 체크리스트를 입력하면, ① 분야별 **수출준비도 점수**를 보여주고
② 실제 수출지원사업(수출바우처·K-SURE 수출보험·해외규격인증·AEO·KOTRA 지사화 등) + 기업마당 지원공고 중
잠재적으로 관련 있는 후보를 넓게 찾아주는 초기 탐색 도구입니다. 정밀한 자동선정 심사기가 아니라, 대표님이
다음 단계(개별 공고 정독·상담)로 넘어가기 전 후보군을 빠르게 좁히는 용도입니다.

[neowiner66-crypto/policy-fund-matcher](https://github.com/neowiner66-crypto/policy-fund-matcher) (정책자금 매칭
어시스턴트)의 아키텍처를 참고해 같은 구조로 새로 작성했습니다.

## 실행 방법

```bash
# 1) 프로젝트 폴더로 이동
cd export-readiness-checker

# 2) (권장) 가상환경 생성 및 활성화
python -m venv venv
source venv/bin/activate  # Windows는 venv\Scripts\activate

# 3) 패키지 설치
pip install -r requirements.txt

# 4) 앱 실행
streamlit run app.py
```

실행 후 자동으로 브라우저가 열리며, 열리지 않으면 터미널에 표시되는 주소(기본값 http://localhost:8501)로
접속하세요. Windows에서는 `run_app.bat`을 더블클릭해도 됩니다.

## 사용 순서

1. **기업정보 입력** — 기본정보 + 54개 수출준비도 자가진단 체크리스트
   - 업종: 키워드 검색 → 한국표준산업분류(KSIC) 대분류/중분류 중에서 선택 → 옆칸에 산업분류코드 자동 표시
   - 사업장 소재지: 시/도 → 시/군/구 2단 선택 (자유입력 오탈자 방지)
   - 지원목적: 신규수출준비 / 해외인증 / 바이어발굴 / 물류·통관 / 보험·자금 / 해외거점 중 선택
2. **준비도·매칭 결과**
   - 9개 분야(제품/품질, 인증/표준, 가격/물류/무역실무, 바이어발굴/마케팅, 계약/법무, 자금/환리스크,
     인력/조직, 온라인수출/디지털, 정책우대)별 충족률과 종합 수출준비도 점수(0~100)를 보여줍니다.
   - 핵심 수출지원사업 + 기업마당 지원공고를 규칙 기반 점수로 정렬한 후보 목록 (참고용 우선순위)
   - 지역 필터: 사업장 소재지와 무관한 지역전용 공고는 자동 제외되고, 전국 대상 공고는 항상 포함됩니다.
   - 업종: 하드 필터링하지 않고 점수 가점 신호로만 사용합니다.
3. **서류·절차 안내** — 선택한 지원사업의 필요서류·접수처·유의사항, 상담 결과 저장

## 지원사업 공고 갱신 (기업마당 연동)

`data/announcements.json`은 기업마당(bizinfo.go.kr) 오픈API에서 "수출" 분야(또는 공고명에 "수출"이 포함된)
공고를 받아온 데이터입니다. 현재 파일에는 웹 검색으로 확인한 2026년 실제 공고 몇 건만 시작 데이터로
들어 있습니다 — 아래 스크립트를 실행하면 최신 전체 목록으로 교체됩니다.

```bash
# .env에 BIZINFO_API_KEY=발급받은인증키 설정 후
python scripts/sync_bizinfo.py
```

- 인증키 발급: https://www.bizinfo.go.kr/apiList.do → 지원사업정보 API → 사용신청 (무상, 즉시 발급)
- 실행할 때마다 그 시점의 "수출" 관련 전체 공고로 `data/announcements.json`을 다시 만듭니다.
- 준비도·매칭 결과 화면에서 "진행중인 공고만 / 마감된 공고도 포함(내년도 재공고 대비)"으로 표시 범위를
  고를 수 있습니다.
- 이 스크립트를 실행한 뒤에는 반드시 Streamlit 앱을 새로고침(또는 재시작)하세요.

## 주의사항

- `data/funds_master.json`(핵심 수출지원사업)은 KOTRA·한국무역보험공사(K-SURE)·중소벤처기업진흥공단·
  관세청의 2026년 공개 자료를 조사해 반영했지만, 한도·지원율·접수기간은 회차별 공고에 따라 달라지므로
  실제 상담에 사용하기 전 각 기관 공식 공고로 반드시 재확인해야 합니다 (각 항목의 `source_url` 참고).
- `checklist.json`(자가진단), `documents_by_fund.json`(서류)은 예시(샘플) 데이터입니다. 실제 상담에
  사용하기 전 각 기관 공식 서류 목록으로 교체해야 합니다.
- `data/ksic_codes.json`(업종 대분류·중분류)과 `data/regions.json`(시/도·시/군/구)은 원본
  policy-fund-matcher 프로젝트에서 재사용한 참고 데이터로, 통계청 공식 조회 사이트로 검증된 원본은
  아닙니다. 실제와 다른 부분이 있으면 알려주세요.
- 본 서비스는 선정을 보장하지 않으며, 점수/체크 항목 수가 많다고 자동 선정이 되는 것도 아닙니다.
  최종 결정은 각 기관 심사에 따릅니다.
- 사업자등록번호·재무제표 등 민감정보는 운영 전환 시 암호화 저장을 전제로 스키마를 다시 설계해야
  합니다 (`database/schema.sql` 주석 참고).
